# Infrastructure as Code: 3-Node Environment (Terraform + Ansible)

## 📌 Overview

This project demonstrates provisioning and configuration of a **3-node infrastructure** using **Terraform** and **Ansible**.

The goal is to build a reproducible Linux environment and practice:

* Infrastructure provisioning
* Configuration management
* Service setup and automation
* Basic networking and monitoring

The setup simulates a minimal production-like environment with separated roles.
